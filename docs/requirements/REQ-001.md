# ذاكرة تتعامل مع الحقائق المتغيّرة
## القصة
بصفتي وكيلاً أريد أن أسترجع أحدث قيمة لأي حقيقة حتى لا أعطي المالك معلومة قديمة.
## المتطلبات (صيغة EARS)
- REQ-001.1 — The memory shall return at most k=6 lines per query.
- REQ-001.2 — When a fact about the same entities and slot arrives, the memory shall replace the older fact.
- REQ-001.3 — If an incoming fact is ≥0.95 similar to a stored fact and does not contradict it, then the memory shall discard it.
